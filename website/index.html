01 / The install

Three steps. No account.

Build the bridge, start OpenCode, and point the app at your private address. The installer writes the token; it never prints it.

  1. 01

    Install the bridge

    Download, verify the checksum, and create a private config.

  2. 02

    Start the agent

    Keep OpenCode on loopback. Use Tailscale for the phone.

  3. 03

    Connect once

    Enter the bridge URL and token. The token stays on the device.

02 / The prerequisites

What has to be true first.

Host

Node.js 22.13 or newer

The bridge is a plain Node service. No database, no daemon, no root.

Host

OpenCode already running

The bridge talks to your local OpenCode on loopback. It does not replace it.

Phone

A private address

Loopback for the same machine, Tailscale or a tunnel for anything else.

Token

One shared secret

The installer generates it and writes it to a mode 600 config file.

03 / The build

Take the beta for a walk.

The beta ships as source, a release-signed Android build, and bridge and web bundles. Keep the bridge private, and expect sharp edges.

Android 7.0+ on arm64. The APK is not distributed through Google Play. Verify it before installing:
