01 / The install

Three steps. No account.

Install once, then use a short command whenever you want a temporary phone link. The one-time setup is verified and keeps the bridge on loopback.

  1. 01

    Install the bridge

    Install the verified bridge and create a private config.

  2. 02

    Start a phone link when needed

    Run opencode-mobile to create a public temporary link after a clear warning and confirmation.

  3. 03

    Connect the app

    Scan the terminal QR or enter its URL and token manually; sign in after connecting.

$ 
installer="$(mktemp)" && trap 'rm -f "$installer"' EXIT && curl -fsSL https://raw.githubusercontent.com/Aetherdz/opencode-mobile-dist/main/install.sh -o "$installer" && bash "$installer" setup

After setup, run opencode-mobile whenever you want to create a phone connection link.

> 
$h = "3a493282e252468ed96012cd0019f5252314bfb5c7b810be34476602616a14aa"
irm https://raw.githubusercontent.com/Aetherdz/opencode-mobile-dist/7c4ec38b7de7d87e88d7f215721a11bc338e128f/install.ps1 -OutFile install.ps1
if ((Get-FileHash .\install.ps1 -Algorithm SHA256).Hash -ne $h) { throw "checksum mismatch" }
.\install.ps1 -Command install -WorkDir "$env:USERPROFILE\projects"
First connection · Linux and macOS

Have Node.js 22+, OpenCode running, and a project folder ready. Setup limits the bridge allowlist to ~/projects by default, not your whole home directory. Then run opencode-mobile, choose private Tailscale or the temporary Cloudflare Quick Tunnel, and scan the terminal QR in the app. The public tunnel is off until you explicitly confirm; the URL and token together grant access, so keep them private. Leave the terminal open while using the temporary link. Full setup, Windows instructions, and troubleshooting.

If an existing session is outside that folder, you can explicitly enable that session in the app. This bridge grant is not an OS sandbox: OpenCode tools still have the filesystem permissions of the process running OpenCode.

02 / The prerequisites

What has to be true first.

Host

Node.js 22 or newer

The bridge is a plain Node service. No database, no daemon, no root.

Host

OpenCode already running

The bridge talks to your local OpenCode on loopback. It does not replace it.

Phone

Private by default

Cloudflare Quick Tunnel is public and temporary; each run requires confirmation. The bridge itself stays on loopback.

Token

One shared secret

The installer generates it and writes it to a mode 600 config file.
