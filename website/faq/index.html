FAQ

Questions worth asking.

The short answers. Longer ones live in the repository docs.

Is this an official OpenCode app?

No. It is an independent client. The OpenCode name and logo belong to the upstream project. This project is not endorsed by the OpenCode team.

Does my code leave my machine?

The bridge talks to OpenCode on loopback. Your device talks to the bridge over your private network. There is no hosted relay and no telemetry. This site reads the public GitHub star count and nothing else. If you configure a third-party push service, it receives a token and a generic notification payload.

Do I need Tailscale?

Only for remote access. On the same machine, loopback is enough. For a phone on another network, Tailscale or an HTTPS reverse proxy is the supported path.

Is there a Play Store or App Store build?

Not yet. Android is a sideloaded beta, release-signed and limited to arm64. iOS is built with EAS and has no TestFlight track in this repository.

Why is model switching missing?

The first beta focuses on a reliable session loop. Model and agent switching will land only when the upstream API exposes stable endpoints; the roadmap tracks it as a post-beta item.

Which languages does the app support?

English, Arabic, and French, with a right-to-left layout for Arabic. The website stays English-only.

Why did the WebSocket token disappear from the URL?

Putting a long-lived credential in a query string leaks it into access logs and proxy traces. The client now asks for a one-time ticket that expires in 30 seconds and is consumed on first use.
