الميزات

الأجزاء التي تستخدمها فعلًا.

ليست لوحة تحكم. سطح صغير وسريع للعمل الذي يجري بين الأمر والتغيير المدموج.

الحلقة

01

كل جلسة في متناول يدك

ابحث عن الجلسات، وجمّعها، وأعد تسميتها، وأنشئها، واحذفها. الجلسات المنتظرة ظاهرة قبل أن تفتحها.

02

بث مباشر يعيد الاتصال

تابع الدور أثناء حدوثه، وتصفّح الرسائل الأقدم، وعُد إلى أحدث رسالة دون أن تفقد الخيط.

03

موافقات مع السياق

راجع الأداة والهدف والفرق قبل أن تسمح. الإجراءات المدمّرة تسأل مرتين.

04

ملفات، لا لقطات شاشة

أرفق الصور ولقطات الكاميرا والمستندات. يجري التحقق عند الجسر، لا في الواجهة وحدها.

05

إشعارات هادئة

إشعارات فورية اختيارية عند انتهاء الأدوار، وعند الأسئلة، وعند الموافقات. تحمل الحمولات معرّفات ونصًا عامًا، لا نصوص الرسائل.

06

ثلاث لغات

الإنجليزية والعربية والفرنسية، مع تخطيط من اليمين إلى اليسار، ونص ثنائي الاتجاه، وسِمَة أحادية اللون لا تشتّت الانتباه.

أين يعمل

Android

ثبّت النسخة التجريبية يدويًا

API 24 أو أحدث. ملف APK التجريبي موقّع للإصدار ومبني لـ arm64-v8a.

arm64 · Expo SDK 58
iOS

ابنِه باستخدام EAS

Expo Router ووحدات أصلية. ابنِ على macOS أو عبر EAS.

TestFlight لاحقًا
Web

ثبّت تطبيق PWA

تصدير ثابت، ووكيل على نفس الأصل، وبلا تخزين مؤقت للجلسات دون اتصال.

Chromium · Firefox · Safari
الجهاز المضيف

شغّل الجسر

Node على Linux أو macOS أو Windows. ووصفات Docker وsystemd.

Node 20+

غير المشمول

تبديل النموذج أو الوكيل، واختيار نموذج لكل جلسة، وبوت Telegram مضمّن، وواجهة سطح مكتب أصلية. يعرض التطبيق مصدر telegram عند استخدام عميل OpenCode آخر، لكنه لا ينفّذ واحدًا.
