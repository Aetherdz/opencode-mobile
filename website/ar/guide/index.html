الدليل

شغّله من البداية إلى النهاية.

الجسر خدمة Node عادية. كل ما يلي جاهز للنسخ واللصق، دون حاجة إلى محرّر.

ابدأ OpenCode

يكتشف الجسر الخدمة المحلية عبر ~/.local/state/opencode/service.json. ويمكنك أيضًا تعيين OPENCODE_URL وOPENCODE_PASSWORD صراحةً؛ ويجب أن يكون العنوان على loopback.

bash 
opencode service start

شغّل الجسر

المثبّت يفعل ذلك نيابةً عنك. شغّله يدويًا حين تريد قراءة الإعدادات أولًا.

bash 
cd bridge
npm ci
cp .env.example .env
openssl rand -hex 32   # put this in AUTH_TOKEN
npm run build
npm start

عيّن ALLOWED_WORKDIRS إلى جذور المشاريع التي تريد كشفها، ثم تحقق من أن الخدمة تستجيب:

bash 
curl http://127.0.0.1:8787/health
{"ok":true}

شغّل التطبيق

لبناء محلي في المتصفح، اسمح بأصل Expo داخل bridge/.env. تتحكم CORS في قراءات المتصفح؛ وهي ليست مصادقة، ولا يزال الرمز الحامل مطلوبًا.

bash 
cd app
npm ci
npx expo start
CORS CORS_ORIGINS=http://localhost:8081,http://127.0.0.1:8081 — أصول محددة فقط. تُرفض أحرف البدل.

الإعدادات

المتغير القيمة الافتراضية الوصف
AUTH_TOKEN مطلوب رمز حامل مشترك، لا يقل عن 32 حرفًا.
HOST 127.0.0.1 عنوان الربط. أبقِه على loopback.
PORT 8787 منفذ HTTP للجسر.
ALLOWED_WORKDIRS المجلد الرئيسي الجذور المسموح بها للجلسات والرفوعات. أبقِها ضيقة.
CORS_ORIGINS فارغ أصول المتصفح المحددة المسموح لها باستدعاء الجسر.
MAX_UPLOAD_MB 25 الحد لكل ملف.
MAX_SESSION_UPLOAD_MB 1024 الحد التراكمي للرفع في الجلسة الواحدة.
RATE_LIMIT_PER_MINUTE 180 حصّة الطلبات غير المصادق عليها لكل IP.

الوصول عن بُعد

الافتراضي الآمن هو loopback مع Tailscale. لا تربط الجسر أبدًا بـ 0.0.0.0 وتعرض المنفذ على الإنترنت.

bash 
tailscale serve --bg http://127.0.0.1:8787

# then enter this in the app
https://<machine>.<tailnet>.ts.net

يعمل نفق SSH أيضًا لاختبار سريع من حاسوب محمول. ويمكن استخدام Cloudflare Tunnel لتجربة قصيرة، لكنه يضع الجسر خلف عنوان عام.
