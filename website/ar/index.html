01 / التثبيت

ثلاث خطوات. بلا حساب.

ثبّت مرة واحدة، ثم استخدم أمرًا قصيرًا كلما احتجت رابطًا مؤقتًا للهاتف. يتحقق المثبّت من الحزمة ويبقي الجسر على loopback.

  1. 01

    ثبّت الجسر

    ثبّت الجسر بعد التحقق وأنشئ إعدادًا خاصًا.

  2. 02

    أنشئ رابط الهاتف عند الحاجة

    شغّل opencode-mobile up لإنشاء رابط عام مؤقت بعد التحذير والموافقة.

  3. 03

    اربط التطبيق

    امسح QR الظاهر في الطرفية أو أدخل الرابط والرمز يدويًا؛ سجّل الدخول بعد الاتصال.

$ 
# نزّل المثبّت وراجعه ثم أعد الإعداد مرة واحدة (Linux/macOS)
curl -fsSLO https://raw.githubusercontent.com/Aetherdz/opencode-mobile-dist/main/install.sh && less install.sh && mkdir -p "$HOME/.local/share/opencode-mobile-installer" && cp install.sh "$HOME/.local/share/opencode-mobile-installer/install.sh" && chmod 700 "$HOME/.local/share/opencode-mobile-installer/install.sh" && bash "$HOME/.local/share/opencode-mobile-installer/install.sh" setup --workdir "$HOME/projects"
# لاحقًا: رابط عام مؤقت بعد التحذير والموافقة
opencode-mobile up
> 
# installer pinned to a commit, verified before it runs
$h = "3a493282e252468ed96012cd0019f5252314bfb5c7b810be34476602616a14aa"
irm https://raw.githubusercontent.com/Aetherdz/opencode-mobile-dist/7c4ec38b7de7d87e88d7f215721a11bc338e128f/install.ps1 -OutFile install.ps1
if ((Get-FileHash .\install.ps1 -Algorithm SHA256).Hash -ne $h) { throw "checksum mismatch" }
.\install.ps1 -Command install -WorkDir "$env:USERPROFILE\projects"

02 / المتطلبات المسبقة

ما يجب أن يتحقق أولًا.

الجهاز المضيف

Node.js 22 أو أحدث

الجسر خدمة Node عادية. بلا قاعدة بيانات، وبلا خدمة خلفية، وبلا صلاحيات جذر.

الجهاز المضيف

OpenCode يعمل بالفعل

يتواصل الجسر مع OpenCode المحلي لديك عبر loopback، ولا يحل محله.

الهاتف

رابط عام مؤقت

استخدم النفق العام المؤقت من opencode-mobile up للوصول من الهاتف.

الرمز

سرّ مشترك واحد

يولّده المثبّت ويكتبه في ملف إعدادات بصلاحيات 600.

03 / الإصدار

جرّب النسخة التجريبية بنفسك.

تصل النسخة التجريبية على شكل مصدر، وبناء Android موقّع للإصدار، وحزم للجسر والويب. أبقِ الجسر خاصًا، وتوقّع أن تصادف بعض الزوايا غير المصقولة.

Android 7.0+ على arm64. لا يوزّع APK عبر Google Play. ثبّته من صفحة الإصدارات بعد إعداد الجسر:

sha256 14eacd032ec5be69c4758032b2108e2a0f37dfd6aa6df2a85535c8d294d8234f

إعداد الجسر تنزيل APK ملفات الإصدار التجريبي المثبّتات SHA256SUMS وملاحظات الإصدار
