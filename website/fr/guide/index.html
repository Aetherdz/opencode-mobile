Guide

De bout en bout.

La passerelle est un service Node ordinaire. Tout ce qui suit se copie-colle, sans éditeur de texte.

Démarrer OpenCode

La passerelle découvre le service local via ~/.local/state/opencode/service.json. Vous pouvez aussi définir OPENCODE_URL et OPENCODE_PASSWORD explicitement ; l’URL doit être en loopback.

bash 
opencode service start

Lancer la passerelle

Le programme d’installation s’en charge pour vous. Lancez-la à la main si vous préférez lire la configuration d’abord.

bash 
cd bridge
npm ci
cp .env.example .env
openssl rand -hex 32   # put this in AUTH_TOKEN
npm run build
npm start

Définissez ALLOWED_WORKDIRS sur les racines de projets que vous souhaitez exposer, puis vérifiez que le service répond :

bash 
curl http://127.0.0.1:8787/health
{"ok":true}

Lancer l’application

Pour une compilation locale destinée au navigateur, autorisez l’origine Expo dans bridge/.env. CORS contrôle les lectures du navigateur ; ce n’est pas une authentification, et le jeton bearer reste obligatoire.

bash 
cd app
npm ci
npx expo start
CORS CORS_ORIGINS=http://localhost:8081,http://127.0.0.1:8081 — origines exactes uniquement. Les caractères génériques sont refusés.

Configuration

Variable Valeur par défaut Description
AUTH_TOKEN obligatoire Jeton bearer partagé, au moins 32 caractères.
HOST 127.0.0.1 Adresse d’écoute. Gardez-la sur loopback.
PORT 8787 Port HTTP de la passerelle.
ALLOWED_WORKDIRS répertoire personnel Racines autorisées pour les sessions et les envois de fichiers. Gardez-la restrictive.
CORS_ORIGINS vide Origines de navigateur exactes autorisées à appeler la passerelle.
MAX_UPLOAD_MB 25 Limite par fichier.
MAX_SESSION_UPLOAD_MB 1024 Plafond cumulé d’envoi par session.
RATE_LIMIT_PER_MINUTE 180 Quota de requêtes non authentifiées par IP.

Accès à distance

La configuration sûre par défaut, c’est loopback plus Tailscale. Ne liez jamais la passerelle à 0.0.0.0 en exposant le port sur internet.

bash 
tailscale serve --bg http://127.0.0.1:8787

# then enter this in the app
https://<machine>.<tailnet>.ts.net

Un tunnel SSH fait aussi l’affaire pour un test rapide depuis un ordinateur portable. Cloudflare Tunnel est envisageable pour une courte expérimentation, mais cela place la passerelle derrière une adresse publique.
