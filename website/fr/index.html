01 / L’installation

Trois étapes. Aucun compte.

Lancez la passerelle, démarrez OpenCode et indiquez à l’application votre adresse privée. Le programme d’installation écrit le jeton ; il ne l’affiche jamais.

  1. 01

    Installer la passerelle

    Téléchargez, vérifiez la somme de contrôle et créez une configuration privée.

  2. 02

    Démarrer l’agent

    Gardez OpenCode sur loopback. Utilisez Tailscale pour le téléphone.

  3. 03

    Se connecter une seule fois

    Saisissez l’URL de la passerelle et le jeton. Le jeton reste sur l’appareil.

$ 
# installer pinned to a commit, verified before it runs
d=$(mktemp -d) && cd "$d"
curl -fsSLO https://raw.githubusercontent.com/Aetherdz/opencode-mobile-dist/7c4ec38b7de7d87e88d7f215721a11bc338e128f/install.sh
echo "d140292ee5f26172a5ff140c693bc38e65bf244c184f4f9e9af7c2a260b596cb  install.sh" | sha256sum -c -
bash install.sh install --workdir "$HOME/projects"

02 / Les prérequis

Ce qui doit être en place avant de commencer.

Hôte

Node.js 22.13 ou plus récent

La passerelle est un simple service Node. Pas de base de données, pas de démon, pas de root.

Hôte

OpenCode déjà en cours d’exécution

La passerelle dialogue avec votre OpenCode local sur loopback. Elle ne le remplace pas.

Téléphone

Une adresse privée

Loopback pour la même machine, Tailscale ou un tunnel pour tout le reste.

Jeton

Un secret partagé

Le programme d’installation le génère et l’écrit dans un fichier de configuration en mode 600.

03 / La version

Emmenez la bêta faire un tour.

La bêta est livrée sous forme de code source, d’une version Android signée pour la version et de paquets pour la passerelle et le web. Gardez la passerelle privée et attendez-vous à quelques aspérités.

Android 7.0+ sur arm64. L’APK n’est pas distribué via Google Play. Vérifiez-le avant de l’installer :

sha256 14eacd032ec5be69c4758032b2108e2a0f37dfd6aa6df2a85535c8d294d8234f
