01 / L’installation

Trois étapes. Aucun compte.

Installez une fois, puis lancez une commande courte pour obtenir un lien temporaire vers le téléphone. La passerelle reste sur loopback.

  1. 01

    Installer la passerelle

    Installez la passerelle vérifiée et créez une configuration privée.

  2. 02

    Créez un lien au besoin

    Lancez opencode-mobile pour créer un lien public temporaire après avertissement et confirmation.

  3. 03

    Connectez l’application

    Scannez le QR du terminal ou saisissez l’URL et le jeton. Connectez-vous ensuite.

$ 
installer="$(mktemp)" && trap 'rm -f "$installer"' EXIT && curl -fsSL https://raw.githubusercontent.com/Aetherdz/opencode-mobile-dist/main/install.sh -o "$installer" && bash "$installer" setup

Après l’installation, lancez opencode-mobile pour démarrer le lien temporaire.

> 
$h = "3a493282e252468ed96012cd0019f5252314bfb5c7b810be34476602616a14aa"
irm https://raw.githubusercontent.com/Aetherdz/opencode-mobile-dist/7c4ec38b7de7d87e88d7f215721a11bc338e128f/install.ps1 -OutFile install.ps1
if ((Get-FileHash .\install.ps1 -Algorithm SHA256).Hash -ne $h) { throw "checksum mismatch" }
.\install.ps1 -Command install -WorkDir "$env:USERPROFILE\projects"

02 / Les prérequis

Ce qui doit être en place avant de commencer.

Hôte

Node.js 22 ou plus récent

La passerelle est un simple service Node. Pas de base de données, pas de démon, pas de root.

Hôte

OpenCode déjà en cours d’exécution

La passerelle dialogue avec votre OpenCode local sur loopback. Elle ne le remplace pas.

Téléphone

Lien public temporaire

Utilisez le tunnel public temporaire de opencode-mobile pour le téléphone.

Jeton

Un secret partagé

Le programme d’installation le génère et l’écrit dans un fichier de configuration en mode 600.
