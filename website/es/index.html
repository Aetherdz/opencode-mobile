01 / La instalación

Tres pasos. Sin cuenta.

Instálalo una vez y usa después un comando corto cuando quieras un enlace temporal para el móvil. El bridge queda en loopback.

  1. 01

    Instalar el puente

    Instala el bridge verificado y crea una configuración privada.

  2. 02

    Crea un enlace cuando lo necesites

    Ejecuta opencode-mobile para crear un enlace público temporal tras el aviso y la confirmación.

  3. 03

    Conecta la aplicación

    Escanea el QR de la terminal o introduce la URL y el token; inicia sesión después.

$ 
# Un comando para configurar (Linux/macOS)
curl -fsSL https://raw.githubusercontent.com/Aetherdz/opencode-mobile-dist/main/install.sh | bash -s -- setup
# Después: ejecuta el mismo comando para crear el enlace temporal
opencode-mobile
>

02 / Los requisitos

Lo que debe cumplirse antes.

Equipo

Node.js 22 o superior

El puente es un servicio Node sencillo. Sin base de datos, sin daemon y sin root.

Equipo

OpenCode ya en ejecución

El puente habla con tu OpenCode local por loopback. No lo reemplaza.

Teléfono

Enlace público temporal

Usa el túnel público temporal de opencode-mobile para el móvil.

Token

Un único secreto compartido

El instalador lo genera y lo escribe en un archivo de configuración con modo 600.

03 / La compilación

Pon a prueba la beta.

La beta se distribuye como código fuente, una compilación de Android firmada para la versión y paquetes del puente y de la web. Mantén el puente en privado y prepárate para encontrar detalles sin pulir.

Android 7.0+ en arm64. El APK no se distribuye a través de Google Play. Instálalo desde la página de versiones después de configurar el bridge:
