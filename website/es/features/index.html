Funciones

Las partes que de verdad usas.

No es un panel de control. Una superficie pequeña y rápida para el trabajo entre una instrucción y un cambio integrado.

El ciclo

01

Todas las sesiones, a mano

Busca, agrupa, renombra, crea y elimina sesiones. Las sesiones en espera se ven antes de abrirlas.

02

Transmisión en vivo que se reconecta

Sigue un turno mientras ocurre, recorre los mensajes anteriores y vuelve al mensaje más reciente sin perder el hilo.

03

Aprobaciones con contexto

Revisa la herramienta, el destino y las diferencias antes de permitir la acción. Las acciones destructivas piden confirmación dos veces.

04

Archivos, no capturas de pantalla

Adjunta imágenes, fotos de la cámara y documentos. La validación ocurre en el puente, no solo en la interfaz.

05

Notificaciones discretas

Notificaciones push opcionales para turnos terminados, preguntas y aprobaciones. Los payloads llevan identificadores y texto genérico, no el contenido de los mensajes.

06

Tres idiomas

Inglés, árabe y francés, con diseño RTL, texto de dirección mixta y un tema monocromático que no estorba.

Dónde se ejecuta

Android

Instala la beta por sideload

API 24 o superior. El APK de la beta está firmado para la versión y compilado para arm64-v8a.

arm64 · Expo SDK 58
iOS

Compila con EAS

Expo Router y módulos nativos. Compila en macOS o en EAS.

TestFlight más adelante
Web

Instala la PWA

Exportación estática, proxy del mismo origen y sin caché offline de las sesiones.

Chromium · Firefox · Safari
Equipo

Ejecuta el puente

Node en Linux, macOS o Windows. Recetas para Docker y systemd.

Node 20+

Lo que no incluye

Cambio de modelo o de agente, elección de modelo por sesión, un bot de Telegram incluido y un contenedor nativo de escritorio. La app muestra un origen telegram cuando se usa otro cliente de OpenCode, pero no implementa ninguno.
