Guía

Ejecútalo de principio a fin.

El puente es un servicio Node corriente. Todo lo que sigue se copia y se pega, sin necesidad de un editor.

Iniciar OpenCode

El puente descubre el servicio local a través de ~/.local/state/opencode/service.json. También puedes definir OPENCODE_URL y OPENCODE_PASSWORD de forma explícita; la URL debe ser loopback.

bash 
opencode service start

Ejecutar el puente

El instalador se encarga de esto. Ejecútalo a mano cuando quieras leer la configuración primero.

bash 
cd bridge
npm ci
cp .env.example .env
openssl rand -hex 32   # put this in AUTH_TOKEN
npm run build
npm start

Define ALLOWED_WORKDIRS con las raíces de proyecto que quieras exponer y comprueba que el servicio responde:

bash 
curl http://127.0.0.1:8787/health
{"ok":true}

Ejecutar la app

Para una compilación local en el navegador, permite el origen de Expo en bridge/.env. CORS controla las lecturas del navegador; no es autenticación y el token bearer sigue siendo obligatorio.

bash 
cd app
npm ci
npx expo start
CORS CORS_ORIGINS=http://localhost:8081,http://127.0.0.1:8081 — solo orígenes exactos. Los comodines se rechazan.

Configuración

Variable Valor predeterminado Descripción
AUTH_TOKEN obligatorio Token bearer compartido, de al menos 32 caracteres.
HOST 127.0.0.1 Dirección de escucha. Mantenla en loopback.
PORT 8787 Puerto HTTP del puente.
ALLOWED_WORKDIRS directorio personal Raíces permitidas para sesiones y subidas. Mantenlas acotadas.
CORS_ORIGINS vacío Orígenes exactos del navegador autorizados a llamar al puente.
MAX_UPLOAD_MB 25 Límite por archivo.
MAX_SESSION_UPLOAD_MB 1024 Tope acumulado de subida por sesión.
RATE_LIMIT_PER_MINUTE 180 Presupuesto de solicitudes sin autenticar por IP.

Acceso remoto

La opción segura por defecto es loopback más Tailscale. Nunca vincules el puente a 0.0.0.0 ni expongas el puerto a internet.

bash 
tailscale serve --bg http://127.0.0.1:8787

# then enter this in the app
https://<machine>.<tailnet>.ts.net

Un túnel SSH también sirve para una prueba rápida desde un portátil. Cloudflare Tunnel es posible para un experimento breve, pero deja el puente detrás de una dirección pública.
