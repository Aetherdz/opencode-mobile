Preguntas frecuentes

Preguntas que vale la pena hacerse.

Las respuestas cortas. Las largas están en la documentación del repositorio.

¿Es oficial esta aplicación de OpenCode?

No. Es un cliente independiente. El nombre y el logotipo de OpenCode pertenecen al proyecto original. Este proyecto no cuenta con el respaldo del equipo de OpenCode.

¿Mi código sale de mi máquina?

El puente habla con OpenCode por loopback. Tu dispositivo habla con el puente a través de tu red privada. No hay relay alojado ni telemetría. Este sitio únicamente lee el número público de estrellas de GitHub. Si configuras un servicio de notificaciones push de terceros, este recibe un token y una carga útil de notificación genérica.

¿Necesito Tailscale?

Solo para el acceso remoto. En la misma máquina, loopback es suficiente. Para un teléfono en otra red, la vía compatible es Tailscale o un proxy inverso con HTTPS.

¿Hay una versión para Play Store o App Store?

Todavía no. Android es una beta instalada al margen de las tiendas, firmada para la versión y limitada a arm64. iOS se compila con EAS y no tiene canal de TestFlight en este repositorio.

¿Por qué falta el cambio de modelo?

La primera beta se centra en un ciclo de sesión fiable. El cambio de modelo y de agente llegará solo cuando la API original exponga endpoints estables; la hoja de ruta lo recoge como un punto posterior a la beta.

¿Qué idiomas admite la aplicación?

Inglés, árabe y francés, con un diseño de derecha a izquierda para el árabe. El sitio web sigue disponible solo en inglés.

¿Por qué desapareció el token del WebSocket de la URL?

Colocar una credencial de larga duración en una cadena de consulta la expone en los registros de acceso y en las trazas de los proxies. Ahora el cliente solicita un ticket de un solo uso que caduca a los 30 segundos y se consume en el primer uso.
